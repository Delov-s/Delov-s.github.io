# 去广告，布局优化，无限会员

> 版本：掌阅8.7.7
>
> `ps`：文章参考了`b`站刷到的一个博主，复现了一下这个过程，但是我在去除开屏广告的时候使用直接替换`xml`界面的方法失败了，去广告是自己分析出来的，其他的部分参考的博主

## `0x01` 去除开屏广告

删除一些与广告相关的文件，删除：`okhttp3,grs_sdk_Server_config.json，zlsioh.dat，supplierconfig.json，ksad_idc.json，gdt_plugin，bdxadsdk.jar`

使用MT管理器自带的Activity记录功能，启动`app`记录

![启动 Activity 记录](/images/zhangyue/image-20260907221443430.png)

定位到`com.chaozh.iReader.ui.activity.WelcomeActivity`，然后使用`JADX-GUI`分析关键代码`onCreate`函数，如图为关键代码，所以当满足`this.f31376v == true`或者 ` z12 == false`时，走无广告分支；`z12`的值与`this.f31377w` 和` zD`有关，当二者都为`true`时`z12`才为`true`,所以直接修改`smali`代码让`zD`为`false`即可。

![WelcomeActivity 关键代码](/images/zhangyue/image-20260908213834421.png)

定位`smali`代码，如图可知`v0`存储的值就是`zD`的值，所以只需要把`move-result v0`改成`const/4 v0,0x0`就能实现去开屏广告

![修改开屏广告判断](/images/zhangyue/image-20260908215551948.png)



如图为修改之前的开屏

![修改前的开屏广告](/images/zhangyue/image-20260907221102986.png)





## `0x02` 布局优化

点击`resources.arsc`，搜索书城，找到如图所示，长按复制ID，然后在`dex`文件里面进行搜索

![资源 ID 定位](/images/zhangyue/image-20260908222845087.png)

定位到`package pf`里面的`p`方法，这里优化掉底部tab栏的书城和会员，注释掉二者对应`add`的`smali`代码。

![底部 Tab 栏代码](/images/zhangyue/image-20260909174247289.png)

还需要替换对应的界面，分析q方法，`i10==1`时返回`bookstore`，`i10==0`时返回`bookshelf`，`i10==2`时返回`VIP`,`i10！=2`时返回`mine`。`smali`代码里面的`p0`对应伪代码的`i10`,`bookstore`对应的代码在`:cond_72`处，把原来`:cond_72`的地方随便命名，这里命名成`:cond_ff`,效果如图所示

```
:cond_72   //添加的代码
.line 1
new-instance p0, Lcom/zhangyue/iReader/ui/fragment/MineFragmen
```

## `0x03`去除顶部签到按钮

> 当联网时书架顶部才会出现签到按钮

搜索`sign`，定位到图片，长按属性。复制资源ID，反编译`dex`文件然后搜索

```
 n.w(this.o.n).b("签到");
 i = 0x7f0806c3;
```

资源ID被赋值给了i，在`actionProvider`被调用，所以只需要把这一行注释掉即可

```
 if (actionProvider instanceof CustomActionProvider) {
 	actionProvider.h(i, ImageView.ScaleType.FIT_CENTER, Util.dipToPixel2(48),Util.dipToPixel2(24));
 }
```






## `0x04`去除本地会员

点击`resources`搜索“您还未登录”并复制资源ID搜索，跳转到v方法

```
invoke-virtual {v0}, Lcom/zhangyue/iReader/account/Account;->v()Z
```

强行返回为真

```
const/4 v0,0x1
return v0
```

然后搜索“试听中”，搜索“VIP”，定位到这里，并跳转到`isBigVip()Z`,强制修改返回为真

```
invoke-virtual {v8}, Lcom/zhangyue/iReader/free/FreeControl;->isBigVip()Z
```

然后就可以使用vip字体和听书。
