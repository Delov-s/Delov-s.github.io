# 网鼎杯bang复现

> 题目是一个安卓逆向脱壳，壳类型为梆梆加固免费版
>
> [^题目有点老了，因为我最近在学习脱壳，拿来练一下]: 

## 1.查壳

[^我目前了解到的查壳工具有两个，其他也有很多，但是我觉得这两个比较实用一点]: 一个`py`脚本，一个`PKID`，其实`GDA`也可以查壳，但是我不太喜欢

### 脚本查壳

`GitHub`地址：[project.ctf.awd.1910.py/src/Tools/Andriod/detect_shell_name/detect_shell_name.py at master · serfend/project.ctf.awd.1910.py]()

直接`cmd`运行即可

```
python detect_shell_name.py apk路径
```

效果如图：![image-20260809214507457](/images/wangdingbei-2020/image-20260809214507457.png)

### `PKID`查壳


# 2.脱壳

> 使用`frida-dexdump`脱壳，我这里使用的`frida`版本是14.2.18，`frida`16版本的我没有运行成功，在启动`frida-dexdump`的时候就直接直接卡住了

启动server端，运行对应的apk

[^真机环境：小米6]: 模拟器运行`apk`直接闪退崩溃了

```
指定App的应用包名：frida-dexdump -U -f com.example.how_debug
```

![image-20260809215438991](/images/wangdingbei-2020/image-20260809215438991.png)

然后会得到两个`dex`文件，直接一起选中拖到jadx-gui里面就可以查看源码，然后得到flag

```
flag{borring_things}
```
